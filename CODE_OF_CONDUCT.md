# Code of Conduct

We want this project to be a friendly, harassment-free place for everyone.

- Be respectful and constructive; criticize code and ideas, not people.
- Assume good faith, and remember that contributors have different backgrounds and experience.
- No harassment, discrimination, personal attacks or unwelcome sexual attention.
- Do not publish other people's private information.

Maintainers may edit or remove comments, commits and issues that violate this, and may block
participants who repeatedly do so. To report a problem, contact the maintainers through the email
address on their GitHub profile.

This text is a short summary in the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
