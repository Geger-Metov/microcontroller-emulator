# Глоссарий и соглашения AVR

| Термин | Что это |
|---|---|
| **PC — в словах** | Счётчик команд считает 16-битные слова. Адрес в `objdump`/HEX (байтовый) = PC × 2. Поэтому вектор `TIMER0_OVF` = слово `0x20` = байт `0x40`. |
| **Двухсловные инструкции** | `JMP`, `CALL`, `LDS`, `STS` занимают 2 слова; PC при обычном продолжении +2. |
| **Адрес данных vs I/O-адрес** | В командах `IN/OUT/SBI/CBI` адрес I/O — `0x00–0x3F`. В пространстве данных (`LD/ST/LDS/STS`, шина) он на **+0x20**. TIFR0: I/O `0x15` → данные `0x35`. |
| **Пространство данных** | `0x00–0x1F` регистры, `0x20–0xFF` I/O, `0x100–0x8FF` SRAM (ATmega328P). |
| **Flash** | 32 КиБ, но адресуется словами; HEX хранит байты. |
| **SREG** | Биты 0..7: `C, Z, N, V, S, H, T, I`. `S = N xor V`. |
| **Липкий Z** | У `SBC`, `SBCI`, `CPC` флаг Z = (результат == 0) **и** старый Z. У `ADC` — обычный. |
| **Вектор прерывания** | Адрес в словах; на 328P вектора занимают 2 слова (`JMP`). `RESET` = 0, `INT0` = 2, … `TIMER0_OVF` = `0x20`. |
| **Приоритет** | Чем меньше адрес вектора, тем выше приоритет (`TIMER0_COMPA` `0x1C` важнее `TIMER0_OVF` `0x20`). |
| **Стек** | Растёт вниз, `PUSH` пишет по SP и уменьшает SP; адрес возврата 2 байта (14-бит PC): сначала младший, затем старший. |
| **RAZ/WI** | Read-As-Zero / Write-Ignored — поведение неизвестного регистра. |
| **TOV0 / OCF0x / TOIE0** | Флаг переполнения / совпадения Timer0 (в `TIFR0`) / бит разрешения в `TIMSK0`. Прерывание идёт при `флаг & маска` и `I=1`. |
| **PINx / DDRx / PORTx** | Вход / направление (1 = выход) / выход (при выходе — уровень, при входе — подтяжка). |
| **`MCUContext`** | Временный набор указателей, из которого `ATmega328P::create()` собирает готовый `EmulatorFacade`. |
